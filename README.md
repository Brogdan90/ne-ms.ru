# ne-ms.ru

Минимальная основа для сайтов и веб-приложений. Стек: **HTML + CSS + JavaScript + Vite**, управление зависимостями через npm.

Этот вариант прост для старта в VS Code: обычные файлы, быстрый сервер разработки и готовая сборка для статического хостинга. React и TypeScript можно добавить, когда появится потребность в сложных интерфейсах. Сервер, база данных и авторизация пока не подключены.

## Что установить

- Node.js 24 LTS (npm входит в установку): https://nodejs.org/
- Git: https://git-scm.com/
- VS Code: https://code.visualstudio.com/

Проект требует Node.js >=22.12.0; рекомендуемая версия указана в `.nvmrc`. После установки Node.js перезапустите терминал и проверьте `node --version` и `npm --version`.

## Первый запуск

В терминале выполните:

```sh
git clone https://github.com/Brogdan90/ne-ms.ru.git
cd ne-ms.ru
npm ci
npm run dev
```

Откройте папку `ne-ms.ru` в VS Code через **File → Open Folder** (или `code .`, если команда доступна). Перейдите по адресу из терминала, обычно http://localhost:5173. Для остановки сервера нажмите Ctrl+C.

**Запускайте проект через `npm run dev`: открытие `index.html` двойным кликом не заменяет сервер разработки.** Кнопка на стартовой странице увеличивает счётчик и позволяет проверить работу JavaScript.

## Структура

| Путь | Назначение |
| --- | --- |
| `index.html` | Главная страница и точка входа |
| `src/main.js` | Логика интерфейса |
| `src/style.css` | Стили |
| `public/` | Статические файлы, которые копируются в сборку без обработки |
| `package.json` | Команды и зависимости |
| `package-lock.json` | Зафиксированные версии для воспроизводимой установки |
| `.gitignore` | Исключает зависимости, сборку, локальные настройки и `.env` |
| `.nvmrc` | Рекомендуемая версия Node.js |

## Сборка и проверка

```sh
npm run build
npm run preview
```

Сборка находится в `dist/`. Адрес просмотра появится в терминале, обычно http://localhost:4173. `preview` предназначен для локальной проверки, а не для production-сервера.

Для статического хостинга (например, Netlify): команда сборки `npm run build`, каталог публикации `dist`. GitHub Pages требует настройки base-пути и отдельного процесса публикации. Этот каркас ничего автоматически не публикует.

## Дальнейшая разработка

1. Меняйте разметку в `index.html`, стили в `src/style.css` и логику в `src/main.js`.
2. При росте проекта разделяйте JavaScript на модули внутри `src/`.
3. Перед коммитом выполняйте `npm run build` и проверяйте страницу в браузере.
4. Коммитьте `package-lock.json`; не коммитьте `node_modules/` и `dist/`.

Не храните секретные API-ключи в клиентском коде. Переменные `VITE_*` включаются в браузерную сборку и публичны. Для секретов и защищённых операций понадобится сервер.
